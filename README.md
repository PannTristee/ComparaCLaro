# ComparaClaro

Sitio web estático en español para comparar productos tecnológicos y consultar guías de compra.

## Estado

Proyecto inicial en preparación. Antes de publicarlo como comparador comercial, sustituye los precios y enlaces de demostración, configura el identificador de afiliado y revisa los textos legales para tu situación.

## Publicación gratuita

Puedes publicar este sitio estático con GitHub Pages desde Settings → Pages, eligiendo Deploy from a branch y la rama `main` con carpeta `/ (root)`, una vez que los archivos del sitio estén en la raíz del repositorio.

## Aviso

No se garantizan ingresos. Los enlaces, precios y datos de productos deben verificarse antes de lanzar el sitio.
