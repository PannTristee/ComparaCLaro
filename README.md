# ComparaClaro

Sitio estático en español para orientar compras de tecnología con guías prácticas y criterios transparentes.

**Web publicada:** https://panntristee.github.io/ComparaCLaro/

## Cómo funciona ahora
- Web estática, sin servidor propio ni costes de hosting.
- Catálogo editorial de categorías con búsqueda y filtro.
- Guías de compra en `guias/`.
- Publicación automática mediante GitHub Actions y GitHub Pages.
- No hay precios en tiempo real ni enlaces de afiliación activos. Las tarjetas llevan a guías, no a ofertas verificadas.

## Publicación
El flujo `.github/workflows/pages.yml` publica el contenido de la raíz mediante GitHub Actions. Para revisar el resultado, consulta la pestaña **Actions** del repositorio y abre la web publicada.

## Antes de monetizar
1. Solicitar y obtener aprobación en programas de afiliación apropiados.
2. Añadir solo enlaces autorizados y probarlos.
3. Mostrar claramente la relación comercial junto a los enlaces.
4. Incorporar precios solo con fuente, fecha de actualización y un proceso fiable de mantenimiento.
5. Completar y revisar los textos legales con los datos reales del responsable y las prácticas efectivas del sitio.
6. Añadir un canal de contacto válido que el responsable controle.

## Principios editoriales
- No inventar precios, disponibilidad, pruebas, valoraciones ni recomendaciones supuestamente independientes.
- Distinguir contenido informativo, datos verificados y publicidad/afiliación.
- Corregir errores y priorizar la utilidad para quien compra.

## Importante
No se garantizan ingresos ni posicionamiento en buscadores. La web es un proyecto inicial y necesita contenido original útil, mantenimiento y revisión antes de operar como comparador comercial.
